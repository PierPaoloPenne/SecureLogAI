02 — What happens next

The pipeline turns noisy machine logs into a ranked anomaly view so you can inspect suspicious activity faster.

1
Parse Auto-detects log format and extracts timestamp, level, source, and message fields.
2
Engineer features Builds behavioral signals from time patterns, bursts, severity, and message signatures.
3
Score anomalies Applies an unsupervised detection model to rank unusual events without labeled examples.
4
Review results Returns a sorted anomaly table plus a visual timeline to inspect suspicious points quickly.
Academic prototype — processing happens locally, nothing is sent to a third party. See docs/architecture.md in the repo for design details.
